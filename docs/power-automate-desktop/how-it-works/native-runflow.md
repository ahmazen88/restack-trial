### Run desktop flow

- **Id:** `runflow/run-desktop-flow`
- **Kind:** native-action
- **Purpose:** Runs desktop flow.

**Use case.** In reusing a tested child desktop flow, drop **Run desktop flow** on the canvas. Runs desktop flow.

**Demonstration.**

```text
**Run desktop flow**
- Desktop flow: `(set in designer)`
- Wait for flow to complete: `True`
```

**Analogy.** One tool in that kit: handing a whole job to another trained clerk and waiting for their folder back.

**In combination.** Run desktop flow and map input/output variables.
