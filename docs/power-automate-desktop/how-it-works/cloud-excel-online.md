# Excel Online (cloud) — how each function works

Default-pane **Excel Online (cloud)** operations. Requires a connection reference. File payloads are binary data.

12 items. Each entry has a use case, a designer-style demonstration, an analogy, and how it combines with neighbors.

### Add a key column to a table

- **Id:** `excel-online/add-a-key-column-to-a-table`
- **Kind:** cloud-connector-operation
- **Purpose:** Adds a key column to a table.

**Use case.** In a workbook in OneDrive/SharePoint, not a local Excel.exe, drop **Add a key column to a table** on the canvas. Adds a key column to a table.

**Demonstration.**

```text
**Add a key column to a table**
- (no inputs)
```

**Analogy.** One tool in that kit: editing the shared Google-style sheet in the browser, but through Excel Online.

**In combination.** List rows present in a table, then Add/Update a row; no Launch Excel instance.
