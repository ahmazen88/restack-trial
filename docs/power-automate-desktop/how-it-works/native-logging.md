### Log message

- **Id:** `logging/log-message`
- **Kind:** native-action
- **Purpose:** Writes a custom Info, Warning, or Error line into run details.

**Use case.** In audit text in the portal run history, drop **Log message** on the canvas. Writes a custom Info, Warning, or Error line into run details.

**Demonstration.**

```text
**Log message**
- Message: `Processed by desktop flow Close-P9`
- Log level: `Info`
```

**Analogy.** Writing a line in the shift diary.

**In combination.** Log message at Info/Warning/Error after each business milestone.
