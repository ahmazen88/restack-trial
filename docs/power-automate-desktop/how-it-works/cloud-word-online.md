# Word Online (cloud) — how each function works

Default-pane **Word Online (cloud)** operations. Requires a connection reference. File payloads are binary data.

### Convert Word Document to PDF

- **Id:** `word-online/convert-word-document-to-pdf`
- **Kind:** cloud-connector-operation
- **Purpose:** Converts word Document to PDF.

**Use case.** In filling a Word template stored in the cloud, drop **Convert Word Document to PDF** on the canvas. Converts word Document to PDF.

**Demonstration.**

```text
**Convert Word Document to PDF**
- (no inputs)
```

**Analogy.** One tool in that kit: a mail-merge without opening Word on the PC.

**In combination.** Populate a Microsoft Word template, then Convert Word Document to PDF.
