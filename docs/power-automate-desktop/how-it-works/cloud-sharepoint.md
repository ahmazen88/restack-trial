# SharePoint (cloud) — how each function works

44 items. Each entry has a use case, a designer-style demonstration, an analogy, and how it combines with neighbors.

- **Kind:** cloud-connector-operation
- **Purpose:** Adds attachment.

**Use case.** In files that live in a team library, not on the bot disk, drop **Add attachment** on the canvas. Adds attachment.
