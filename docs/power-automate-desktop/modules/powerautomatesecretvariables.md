# Power Automate secret variables

Resolve credentials stored in the Power Automate portal.

This page documents every **native action** in this group (1 items).

## Actions

### Get credential

- **Inventory id:** `powerautomatesecretvariables/get-credential`
- **Kind:** native-action
- **Purpose:** Reads credential into a flow variable.
- **Key inputs:** `Credential` (Text value); `Timeout` (Numeric value)
- **Produces:** `Credential` (Credential)
- **Exceptions:** `Failed to get credential`; `Invalid credentials configuration`; `Credential timed out`; `Failed to contact credentials vault`
- **Microsoft Learn:** [Get credential](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/powerautomatesecretvariables#getcredentialaction)
