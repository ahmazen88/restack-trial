# Power Platform

Launch a Power App from the desktop flow and exchange inputs/outputs.

This page documents every **native action** in this group (1 items).

## Actions

### Run Power App (preview)

- **Inventory id:** `power-platform/run-power-app`
- **Kind:** native-action
- **Purpose:** Launches a canvas app from the desktop flow, passes values in, and collects values the app returns. Needs PAD 2.68+.
- **Key inputs:** `App` (Power App)
- **Produces:** None listed
- **Exceptions:** none listed
