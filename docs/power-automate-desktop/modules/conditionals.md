# Conditionals

Branch with If / Else if / Else and Switch / Case / Default case.

This page documents every **native action** in this group (6 items).

## Actions

### Case

- **Inventory id:** `conditionals/case`
- **Kind:** native-action
- **Purpose:** One match arm inside a Switch block.
- **Key inputs:** `Operator` (Equal to (=), Not equal to (<>), Greater than (>), Greater than or equal to (>=), Less than (<), Less than or equal to (<=), Contains, Does not contain, Is empty, Is not empty, Starts with, Does not start with, Ends with, Does not end with, Is blank, Is not blank); `Value to compare` (*)
- **Produces:** None listed
- **Exceptions:** none listed
- **Microsoft Learn:** [Case](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/conditionals#case)

### Default case

- **Inventory id:** `conditionals/default-case`
- **Kind:** native-action
- **Purpose:** Fallback arm when no Case in a Switch matches.
- **Key inputs:** None
- **Produces:** None listed
- **Exceptions:** none listed
- **Microsoft Learn:** [Default case](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/conditionals#casedefault)

### Else

- **Inventory id:** `conditionals/else`
- **Kind:** native-action
- **Purpose:** Runs when no earlier If / Else if condition was true.
- **Key inputs:** None
- **Produces:** None listed
- **Exceptions:** none listed
- **Microsoft Learn:** [Else](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/conditionals#else)

### Else if

- **Inventory id:** `conditionals/else-if`
- **Kind:** native-action
- **Purpose:** Tests another condition after an If that did not match.
- **Key inputs:** `Operator` (Equal to (=), Not equal to (<>), Greater than (>), Greater than or equal to (>=), Less than (<), Less than or equal to (<=), Contains, Does not contain, Is empty, Is not empty, Starts with, Does not start with, Ends with, Does not end with, Is blank, Is not blank); `First operand` (*); `Second operand` (*)
- **Produces:** None listed
- **Exceptions:** none listed
- **Microsoft Learn:** [Else if](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/conditionals#elseif)

### If

- **Inventory id:** `conditionals/if`
- **Kind:** native-action
- **Purpose:** Marks the beginning of a block of actions that is run if the condition specified in this statement is met.
- **Key inputs:** `Operator` (Equal to (=), Not equal to (<>), Greater than (>), Greater than or equal to (>=), Less than (<), Less than or equal to (<=), Contains, Does not contain, Is empty, Is not empty, Starts with, Does not start with, Ends with, Does not end with, Is blank, Is not blank); `First operand` (*); `Second operand` (*)
- **Produces:** None listed
- **Exceptions:** none listed
- **Microsoft Learn:** [If](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/conditionals#if)

### Switch

- **Inventory id:** `conditionals/switch`
- **Kind:** native-action
- **Purpose:** Routes execution to the Case that matches an expression.
- **Key inputs:** `Value to check` (*)
- **Produces:** None listed
- **Exceptions:** none listed
- **Microsoft Learn:** [Switch](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/conditionals#switch)
