# Excel Online (Business) (cloud connector)

Tables, worksheets, rows, and Office Scripts in workbooks stored in the cloud.

This page documents every **cloud connector operations** in this group (12 items).

## Operations

### Add a key column to a table

- **Inventory id:** `excel-online/add-a-key-column-to-a-table`
- **Kind:** cloud-connector-operation
- **Purpose:** Adds a key column to a table.

### Add a row into a table

- **Inventory id:** `excel-online/add-a-row-into-a-table`
- **Kind:** cloud-connector-operation
- **Purpose:** Adds a row into a table.

### Create table

- **Inventory id:** `excel-online/create-table`
- **Kind:** cloud-connector-operation
- **Purpose:** Creates table.

### Create worksheet

- **Inventory id:** `excel-online/create-worksheet`
- **Kind:** cloud-connector-operation
- **Purpose:** Creates worksheet.

### Delete a row

- **Inventory id:** `excel-online/delete-a-row`
- **Kind:** cloud-connector-operation
- **Purpose:** Deletes a row.

### Get a row

- **Inventory id:** `excel-online/get-a-row`
- **Kind:** cloud-connector-operation
- **Purpose:** Reads a row into a flow variable.

### Get tables

- **Inventory id:** `excel-online/get-tables`
- **Kind:** cloud-connector-operation
- **Purpose:** Reads tables into a flow variable.

### Get worksheets

- **Inventory id:** `excel-online/get-worksheets`
- **Kind:** cloud-connector-operation
- **Purpose:** Reads worksheets into a flow variable.

### List rows present in a table

- **Inventory id:** `excel-online/list-rows-present-in-a-table`
- **Kind:** cloud-connector-operation
- **Purpose:** Lists rows present in a table.

### Run script

- **Inventory id:** `excel-online/run-script`
- **Kind:** cloud-connector-operation
- **Purpose:** Runs script.

### Run script from SharePoint library

- **Inventory id:** `excel-online/run-script-from-sharepoint-library`
- **Kind:** cloud-connector-operation
- **Purpose:** Runs script from SharePoint library.

### Update a row

- **Inventory id:** `excel-online/update-a-row`
- **Kind:** cloud-connector-operation
- **Purpose:** Updates a row.
