# Google Cognitive

Call Google Cloud Natural Language and Vision APIs.

This page documents every **native action** in this group (9 items).

## Actions

### Analyze entities

- **Inventory id:** `googlecognitive/analyze-entities`
- **Kind:** native-action
- **Purpose:** Invokes the Google Cloud Natural Language service named 'Analyze Entities'.
- **Key inputs:** `API key` (Text value); `Document type` (Plain text, HTML); `Provide file` (From file, From GCS); `File path` (File); `GCS URL` (Text value); `Language` (Text value; optional); `Timeout` (Numeric value; optional)
- **Produces:** `JSONResponse` (Custom object); `StatusCode` (Numeric value)
- **Exceptions:** `Failed to Invoke cognitive services`; `Request timeout expired`
- **Microsoft Learn:** [Analyze entities](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/googlecognitive#analyzeentitiesgoogle)
