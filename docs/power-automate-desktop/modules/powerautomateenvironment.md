# Power Automate environment

Read Dataverse environment variables, including secrets at runtime.

This page documents every **native action** in this group (1 items).

## Actions

### Retrieve environment variable

- **Inventory id:** `powerautomateenvironment/retrieve-environment-variable`
- **Kind:** native-action
- **Purpose:** Retrieves environment variable.
- **Key inputs:** `Environment variable` (Text value)
- **Produces:** `EnvironmentVariableValue` (*Depends on the selected environment variable type*)
- **Exceptions:** `Retrieve environment variable failed`
- **Microsoft Learn:** [Retrieve environment variable](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/powerautomateenvironment#retrieveenvironmentvariable)
