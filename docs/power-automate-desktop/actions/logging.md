# Logging

Write custom log entries during a desktop flow run.

- Actions in this module: **1**
- Official docs: [Logging actions](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/logging)

## Actions

### Log message

Adds a custom text message to the flow run action details.

Designer name: **Log message**. Official reference: [Logging / Log message](https://learn.microsoft.com/en-us/power-automate/desktop-flows/actions-reference/logging#logmessage).

**Inputs**

| Parameter | Required | Accepts | Default |
|---|---|---|---|
| Message | Required | Text value | — |
| Log level | Choice | Info, Warning, Error | Info |

Produces no variables.

No module-specific exceptions are listed for this action.
