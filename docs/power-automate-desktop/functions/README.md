# Functions, types, and properties

PAD has two formula languages plus a large set of **data-type properties** that behave like functions (`%InvoiceDate.Year%`).

| Page | Use when |
|---|---|
| [Classic `%` notation](percent-notation.md) | The flow was created **without** Power Fx. |
| [Power Fx functions](power-fx.md) | The flow was created **with** Power Fx enabled. |
| [Data types](data-types.md) | You need to know what an action returns. |
| [Data-type properties](data-type-properties.md) | You want a field off a file, list, mail message, or instance. |

Most classic flows do string and date work with **Text** and **Date time** actions rather than formulas. Power Fx flows can do that work in the formula bar instead.
